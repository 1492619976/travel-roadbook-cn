潮汕 4 天 3 晚 · 不走回头路

高铁进 · 落地自驾 · 单向贯穿：潮州 → 南澳（南线进岛 / 北线出岛）→ 汕头 → 返程
🚄 上海虹桥 → 潮汕站 → 🚗 潮州古城 → 官塘 → 🌉 南澳大桥 → 青澳湾 → 🚗 深澳·后宅 → 汕头小公园 → 🚄 汕头站
≈350 km落地自驾总里程（含环岛）
¥96南澳大桥进岛费（出岛免费）
2 处日落 + 1 场日出风车山/彩虹码头 · 青澳湾
23 家店 + 7 个点位全部来自小红书高赞实拍笔记
≈6-7.5k/2人预算参考（笔记实游记口径）

🗺️ 路线地图示意路线 · 坐标为大致位置，精确导航请点各卡片「高德导航」

D1 潮州古城 D2 南线进岛 D3 北线出岛→汕头 D4 返程
底图（高德瓦片）加载需联网；Leaflet 已内嵌本文件。本示例未嵌图片（--no-images 模式）。南澳岛内「南线进、北线出」形成完整环线，桥只在进岛走一次。

📅 每日节奏一天一个主题，跨城日主动减量

Day 1

潮州古城 · 夜与灯

午后抵站租车，下午 4 点后进古城：开元寺→甲第巷→广济桥过河拆桥→滨江长廊→广济楼→20:00 灯光秀→牌坊街夜市

Day 2

官塘牛肉 → 南澳南线

10 点前吃官塘牛肉火锅，过桥进岛走南线：长山尾→钱澳湾→云澳→青澳湾入住；傍晚风车山/彩虹码头看日落

Day 3

日出 → 北线出岛 → 汕头

青澳湾看日出，北线竹栖渡湾→深澳→雄镇关→后宅早午餐，出岛进汕头：小公园骑楼 citywalk，夜宵双生不夜粥

Day 4

汕头收尾 · 返程

福记豆浆早餐，补吃+买手信（猪肉脯/牛肉丸），午后汕头站还车，高铁返沪

🧭 逐日详单时间块为建议节奏，非分钟级班表

🟠 Day 1 · 潮州古城（夜与灯）

高铁午后到 → 租车 → 「下午 4 点出发不走回头路」经典动线（笔记实测：避开暴晒和人头）
上午
上海虹桥 → 潮汕站（高铁约 7.5h，班次以 12306 为准；或飞揭阳潮汕机场约 2.5h）机场/车站取租车——记住：全险
15:30
进潮州古城，行李寄存牌坊街口或先去民宿车停凤城公园停车场，别在古城里找车位
16:00
开元寺（免费，唐代古刹，屋顶嵌瓷；避开 12:00–13:00 午休）→ 甲第巷（大户人家府邸，游客罕至）
17:10
广济桥 ¥20：每个桥亭匾额石刻慢慢看⭐17:30 蹲「过河拆桥」浮桥拆解，桥上等韩江日落
18:30
滨江长廊：拍广济桥全景最佳机位，黄昏蓝调时刻
19:30
广济楼登楼 ¥30 俯瞰古城 → 20:00 广济桥灯光秀（周五—周日加场 21:30；不用上桥，岸边免费看）
20:30
牌坊街夜市收尾：23 座明清牌坊夜色最有味道小吃：顺伯反沙屋 · 一杯潮茶 · 潮涂记腐乳鸡翅 · 陆彬记卤鹅；宵夜砂锅粥（阿荣/锐记）
🛏 住潮州古城内/古城边｜🚗 步行日，车歇着

🟢 Day 2 · 官塘牛肉 → 南澳岛南线进岛

一路向东南：韩江东岸吃牛肉 → 过桥 → 南岸海景公路直奔青澳湾（下午打光面海，拍照好看）
09:30
官塘兄弟牛肉·总店早午火锅：10 点前到肉最全、鲜牛肉丸必点两篇笔记评价「肉嫩但不惊艳」，介意可换「生记官塘牛肉」；官塘在潮州东郊，顺路不绕
11:00
出发过南澳大桥（进岛 ¥96，出岛免费），约 1h节假日桥上可能堵半小时+，错峰
12:30
长山尾灯塔（红塔+大桥同框）→ 南线：田仔观海平台 → 钱澳湾灯塔（海边栈桥，电影感）
15:00
云澳 · 三囱崖灯塔顺路 → 青澳湾入住海景公寓笔记实住 100–300/晚；下午人多正常，价值在明早日出
17:00
蛴仔澎风车山（导航「19 号风车」）或 彩虹码头看日落彩虹码头：日落前海面彩色、日落时金黄（笔记原话）
19:00
晚饭 浩利食店（人均 40+，「南澳最好吃的一顿」）或后宅 黄记沙嗲面甜品：然记糖水铺 / 兴兴反沙；胆大加然孖生腌
🛏 住青澳湾海景公寓｜🚗 当日约 110km

🔵 Day 3 · 青澳湾日出 → 北线出岛 → 汕头

北线（竹栖渡湾—深澳—雄镇关—后宅）与昨日南线合成完整环线——岛内也零回头路
05:40
青澳湾日出：下楼就是沙滩；顺路 北回归线·自然之门打卡比「海泉湾墙/北回归线广场」值
08:00
北线出岛：竹栖渡湾（避雷贴作者心中「岛上最好的地方」，人少水净）→ 深澳总兵府（顺路可选）→ 雄镇关 → 后宅镇早午餐后宅吃老牌沙嗲面/打包谢真真糯米糍
11:00
过桥出岛（免费）→ 汕头约 1h；西堤公园停车
12:30
午餐 杏花吴记牛肉火锅（人均 120，错峰）或 五洲牛肉馆（11 点去包场）
14:30
Citywalk：汕头旅社 → 小公园 → 老妈宫戏台 → 邮政总局 → 开埠文化陈列馆骑楼建筑群很复古，商拍摄影多
18:00
龙眼南路美食街：蔡大胆捞面 / 如如糯米铺 / 兴欣荣鸡翅 / 叔公手作 / 阿群甘草水果
22:00
双生不夜粥深夜食堂：10 点后到不用排队，酸菜东星斑
🛏 住万象城/龙眼南路附近｜🚗 当日约 110km

🟣 Day 4 · 汕头收尾 → 返沪

早餐–补吃–手信–还车，午后高铁走人（汕头站出发，不用折回潮汕站）
08:30
老牌福记加浓豆浆+油条开胃；再来份小吴肠粉（评价两极，自行验证）
10:00
补漏任选：金砂阿洲鱼册店 / 龙香酒家 / 瑞娇嫲嫲生腌 / 陶家功夫卤鹅；买手信：钟福记猪肉脯 + 牛肉丸
14:00
汕头市区/汕头站还车（异地还车费下单时看清）
15:00+
汕头站 → 上海虹桥高铁返程班次以 12306 为准；若飞返需回揭阳机场（约 1h，略回头），高铁更契合本线路
